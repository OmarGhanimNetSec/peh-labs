\# Practical Ethical Hacking (PEH) Labs



Lab write-ups and screenshots from Practical Ethical Hacking exercises on Kali Linux and Wireshark.



> \*\*Note:\*\* For educational and authorized lab/classroom use only.



\## Repository Structure



\### `network-and-wireshark/`

\- `Wireshark\_Assignment-Formative 1 (Omar NV24176)-1.docx` — Capturing and analyzing ICMP ping requests/replies and IPv4 source/destination addresses in Wireshark.

\- `PEH ass(1).docx` — Comparing `ip a`, `ifconfig`, and `ip r` outputs and testing `chmod` permissions on files.

\- `Assignment 1.docx` — Network interface/routing reconnaissance notes (`ifconfig`, `ip a`, `ip r`) and file permission checks.



\### `linux-permissions/`

\- `FOrmative assement.docx` — DNS query/response packet analysis in Wireshark plus practical Linux `r`, `w`, and `x` permission tests on files and directories.



\### `netcat-shells/`

\- `PEH101 revers shell.docx` — Netcat (`nc`) listener and shell connection exercises (`nc -nvlp`, `whoami`, `su root`).
